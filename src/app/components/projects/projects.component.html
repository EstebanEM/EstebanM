MUNDIAL DE FUTBOL
Este proyecto fue un reto y entregable desarrollado en el SENA, donde creamos una interfaz enfocada en la temática del Mundial de Fútbol. El sistema incluye un index, un login de registro de usuario y un dashboard con un CRUD de jugadores seleccionados. Me desempeñé en el desarrollo Front-End, realizando la maquetación de las interfaces en HTML, CSS y JavaScript, cuidando cada detalle visual para lograr una experiencia atractiva y funcional. En la parte Back-End, se implementó el registro de usuarios utilizando Python y MySQL para la gestión de datos. Trabajé en conjunto con el equipo Back-End para asegurar la correcta integración de la interfaz con la lógica del sistema, aplicando buenas prácticas de estructura y modulación en el código.
