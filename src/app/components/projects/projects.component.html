Gestión de datos con PhpMyAdmin

Trabajo Back-End enfocado en la gestión de bases de datos y flujos de pago, desarrollando soluciones personalizadas en entornos cPanel, WordPress y PhpMyAdmin.

Participé activamente en la creación, administración y mantenimiento de tablas personalizadas para la gestión de usuarios y pagos, utilizando PHP para establecer conexiones seguras entre el Front-End, WordPress y la base de datos.

Se desarrollaron scripts PHP dedicados para el manejo de información proveniente del módulo “Pagar cuota”, permitiendo registrar y validar cada transacción de forma estructurada y confiable.

  • Conexión a base de datos mediante scripts PHP personalizados
  • Creación y gestión de tablas en PhpMyAdmin
  • Validación y almacenamiento de datos de usuarios y pagos
  • Integración con WordPress desde cPanel

Se implementaron dos tablas principales para el control financiero:

  • Tabla de pagos del módulo “Pagar cuota”, encargada de recibir y almacenar los datos enviados desde el formulario de pago.
  • Tabla de pagos procesados por Bold, alimentada automáticamente mediante la implementación de webhooks y el botón de pagos de la plataforma.

Ambas tablas almacenan información clave como: cédula del usuario, número de cuota, monto, estado de la cuota, fecha y hora del pago, ID de la cuota y correo electrónico, permitiendo un seguimiento completo y ordenado de cada transacción.

Esta implementación garantiza trazabilidad, control y confiabilidad en el manejo de pagos, facilitando la validación financiera y la integración con otros módulos del sistema.
